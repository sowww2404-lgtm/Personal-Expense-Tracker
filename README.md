# 💰 Personal Expense Tracker

A simple and responsive web-based **Personal Expense Tracker** developed using HTML, CSS, JavaScript, jQuery, Bootstrap 5, and LocalStorage.

This project was developed as part of my **Web Development – Front-End Internship**.

## 📌 About the Project

The Personal Expense Tracker is a web application designed to help users record, view, and manage their daily expenses in a simple and organized way.

Users can enter expense details such as the expense name, amount, and category. The application stores the expense records using **LocalStorage**, allowing the data to remain available even after refreshing or reopening the browser.

The project demonstrates the practical use of front-end web technologies to create a responsive and user-friendly application.

## ✨ Features

- ➕ Add new expense records
- 👀 View the list of expenses
- 🗑️ Delete unwanted expenses
- 💾 Store expense data using LocalStorage
- 📊 Display expense records in a table
- 💰 Calculate and display total expenditure
- 📱 Responsive user interface
- 🖥️ Works across different screen sizes
- 🔄 Data persistence after page refresh
- 🎨 Simple and user-friendly design

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page
- **CSS3** – Styling and layout
- **JavaScript** – Application logic and expense management
- **jQuery** – Event handling and DOM manipulation
- **Bootstrap 5** – Responsive and user-friendly interface
- **LocalStorage** – Browser-based data storage

## ⚙️ How It Works

1. The user enters the expense name, amount, and category.
2. The system captures and validates the entered information.
3. The expense data is stored in the browser using LocalStorage.
4. The expense is displayed in the expense table.
5. The total expenditure is updated based on the stored expenses.
6. Users can delete an expense whenever required.
7. Saved expenses are automatically retrieved when the page is refreshed or reopened.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `vendor` folder.
3. Open `index.html` in a web browser.
4. Start adding and managing your expenses.

## 💡 System Architecture

The application runs completely in the web browser without requiring a server or database.

The main components are:

* **User Interface** – Allows users to enter and view expense details.
* **JavaScript Logic** – Processes user input and manages expense data.
* **LocalStorage** – Stores expense records in the browser.
* **Web Browser** – Executes the application and displays the interface.
